# Open Questions Inventory (template)

Design ambiguities that need resolution before work can proceed. Each question blocks one or more requirements.

## Process

1. When you find an ambiguity while working, add it here
2. Mark the affected requirement(s) as `BLOCKED` with a reference to the OQ
3. Assign an owner to resolve the question
4. When resolved, update the source doc and mark the OQ as RESOLVED
5. The blocked requirements can then be unblocked

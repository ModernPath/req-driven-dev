# Gap Register (template)

Known capability gaps — features we know we need but are explicitly deferring.

## Process

1. When you identify a capability gap, add it here
2. Create a `DEFERRED` requirement in the owning context's ledger
3. Track the gap with a reference to where it's needed
4. When ready to address, move to the requirements backlog
